# The Readly Institute — Online Academy (React 2.0)

Premier live online tutoring academy for Cambridge Assessment International Education (O-Level, IGCSE & A-Level), Pearson Edexcel, and IT Professional Certifications.

## 🚀 Key Features

- **React 18 Single Page Application (SPA):** Built with modern functional components, hooks, and React Router v6 for instantaneous, smooth client-side routing.
- **Vite Build Tooling:** Lightning-fast HMR and optimized production bundling with Tailwind CSS.
- **196+ Worldwide Country Code Selector:** Integrated with official flag emojis and international dialing codes across all booking and contact forms.
- **⚡ Dual Backend Integration (Zero Server Costs):**
  - **Google Sheets Real-time Logging:** Automatically records student inquiries into Google Sheets via Google Apps Script Web App.
  - **Instant WhatsApp Dispatch:** Automatically opens WhatsApp with a pre-filled, polite student-perspective message addressed to official admissions (+92 333 7221552).
- **Interactive Modals:** Dynamic Free Demo Booking dialog box, Faculty Profile modal with tutor credentials, and Subject Syllabus blueprint modal.
- **Complete Academic Catalog:** Cambridge O-Level, Cambridge IGCSE, Cambridge A-Level, Pearson Edexcel, and high-demand IT Certifications (Digital Marketing, CSIS Cyber Defense, Web Development, Python AI).

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Opens the local server at `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```
Generates optimized static assets in the `dist/` directory ready for deployment on Netlify, Vercel, or any static hosting platform.
